# abuhazafa.com

Source code of the personal academic website of **Abu Hazafa, PhD**, a computational
and translational oncology researcher.

**Website:** https://abuhazafa.com

## Contents

The site presents my research profile: research vision and interests, research
experience and projects, publications with citation export (APA, BibTeX and RIS),
education, skills, training, honours and contact details.

## Built with

- HTML, CSS and JavaScript, with no framework or build step
- GitHub Pages hosting with a custom domain
- Font Awesome and Academicons icons; Inter and Source Serif 4 fonts
- GoatCounter for privacy-friendly visitor statistics and Formspree for the contact form
